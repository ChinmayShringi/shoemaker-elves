# Add Particles.js background effect

Edit the existing `index.html` to add an interactive particle background using particles.js (via CDN).

Requirements:
- Add the particles.js CDN script: https://cdn.jsdelivr.net/particles.js/2.0.0/particles.min.js
- Initialize particles.js on the `#particles-bg` div that already exists in the HTML
- Configuration:
  - 80 particles, white color (#ffffff), opacity 0.5, size between 1-3px
  - Lines connecting nearby particles, white, opacity 0.2, distance 150
  - Particles should move slowly and randomly (speed 1-2)
  - On hover: "grab" mode that connects particles to the cursor with lines (distance 200)
  - On click: "push" mode that adds 4 new particles
  - Responsive: reduce to 40 particles on screens under 768px
- The particles should appear behind all other content (the #particles-bg div already has z-index: 0)
- Add the initialization script in a `<script>` tag at the bottom of the body
- Do NOT modify the hero section or the threejs-container -- only add the CDN script tag and the initialization script
