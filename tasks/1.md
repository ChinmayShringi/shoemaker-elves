# Create base HTML page

Create a single `index.html` file with the following:

- A full dark-themed page (background: #0a0a0a)
- A centered hero section with:
  - A large heading "Welcome to the Future" in white, using Google Fonts (Inter or Space Grotesk)
  - A subtitle paragraph "An experiment in web visuals" in gray (#888)
  - A glowing neon-style button that says "Explore" with a hover animation (subtle scale + glow)
- Use a CSS reset and set box-sizing: border-box globally
- The page should be responsive and look good on mobile
- All CSS should be in a `<style>` tag inside the HTML (no external CSS files)
- Add a `<div id="particles-bg"></div>` as the first child of body, positioned absolute, covering the full viewport, with z-index: 0. Leave it empty for now -- it will be used later for particle effects.
- Add a `<div id="threejs-container"></div>` after the hero section, 400px tall, full width, with z-index: 1. Leave it empty for now -- it will be used later for 3D content.
- Make sure the hero section has z-index: 2 so it sits above both containers.
