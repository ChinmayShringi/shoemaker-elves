# Add Three.js 3D rotating geometry

Edit the existing `index.html` to add a 3D scene using Three.js (via CDN) inside the `#threejs-container` div.

Requirements:
- Add the Three.js CDN script: https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
- Create a Three.js scene rendered inside the `#threejs-container` div that already exists
- The scene should contain:
  - A wireframe icosahedron (IcosahedronGeometry, radius 2, detail 1) in the center
  - The wireframe material should be a bright cyan color (#00ffff) with 0.6 opacity
  - A second smaller wireframe octahedron (OctahedronGeometry, radius 1) orbiting around the icosahedron
  - The octahedron material should be magenta (#ff00ff) with 0.6 opacity
- Animation:
  - The icosahedron rotates slowly on X and Y axes
  - The octahedron orbits around it (use sin/cos on a time variable for circular motion, radius 4)
  - The octahedron also rotates on its own axis
- Camera: PerspectiveCamera, positioned at z=8
- Renderer: transparent background (alpha: true) so the dark page background shows through
- Make the renderer resize responsively with the container
- Add the Three.js script and initialization code in a `<script>` tag at the bottom of body, after the particles.js script
- Do NOT modify the particles.js code or the hero section
